# はしる、ずっと

指でぐるぐる回して、東京・日本橋から大阪・通天閣まで、東海道(国道1号)を走り続けるドット絵ゲームです。着いたら折り返して、何往復でも。

- 操作: 画面の下半分を指でぐるぐる回す。速く回すと速く走ります(パソコンはマウスで円を描く)。
- 1往復は約7分。1往復で季節が1つ進み、4往復で1年、主人公が1歳年を取ります。
- 宿場57か所のスタンプ集め。各宿場には取れる季節が決まっています(図鑑で確認できます)。
- 57か所すべて集めると、花火と「全宿場 制覇！」の演出のあと、フィーバーモードに入ります。画面が虹色にギラギラし、走った距離40kmごとにフィーバーレベルが上がって、速度が ×1.5 から最大 ×6 までインフレしていきます(進み具合は保存されます)。
- 名所の見せ場が11か所(日本橋・横浜・箱根・富士山・浜名湖・名古屋城・鈴鹿峠・琵琶湖・三条大橋・伏見・通天閣)。
- 進み具合・スタンプは端末に自動保存されます。別のタブに移っても、戻ると続きから再開します。
- 画像・音楽・効果音はすべてコードで生成したオリジナルです。外部の画像や音源は使っていません。
- 依存ライブラリなし。ビルド不要。文字は Google Fonts の DotGothic16(読み込めないときは端末の日本語フォント)。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体(HTML・CSS・JavaScript) |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコンの設定 |
| `sw.js` | オフラインで遊べるようにするキャッシュ処理 |
| `icons/` | アプリのアイコン |

## ローカルで動かす

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` を直接開いても遊べますが、オフライン対応(Service Worker)は `http://localhost` か `https://` のときだけ有効です。

## GitHub Pages で公開する

1. GitHub で空のリポジトリを作る(例: `hashiru-zutto`)。
2. Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存する。
3. 数分後に `https://<ユーザー名>.github.io/hashiru-zutto/` で遊べる。

## 更新したとき

`index.html` などを変えたら、`sw.js` の `VERSION`(例: `hashiru-v1` → `hashiru-v2`)も変えてください。変えないと、すでに遊んだ端末で古い版が表示され続けます。

## 開発用

URL の末尾に `#debug` を付けると、季節・名所・宿場を飛ばすテスト用ボタンが出ます。「全スタンプ」で全制覇の演出から、「フィーバー」でフィーバーモードの途中から確認できます。
